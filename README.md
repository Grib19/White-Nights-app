# White Nights

Социальная сеть с сайтом (компьютер и телефон), приложением для Android и приложением для Windows.

## Планируемый стек

| Часть | Технология | Назначение |
|---|---|---|
| Бэкенд | Supabase (бесплатный тариф) | Авторизация, база данных Postgres, хранение файлов, обновления в реальном времени |
| Сайт | React + Vite | Один код для компьютеров и телефонов, без отдельного сервера |
| Android | Capacitor, сборка APK через GitHub Actions | Установка файлом APK, без Google Play |
| Windows | Tauri, сборка через GitHub Actions | Установщик для Windows |
| Хостинг сайта | Cloudflare Pages | Бесплатная публикация при обновлении `main` |

Все сервисы выбраны так, чтобы работать на бесплатных тарифах. Вход по почте и паролю, телефон проверяет комсостав вручную (SMS платные).

## Структура

```
docs/             описание идеи, функций, решений
web/              сайт (Next.js), общий для всех платформ
mobile-android/   сборка Android через Capacitor
desktop-windows/  сборка Windows через Tauri или Electron
supabase/         миграции базы данных и настройки Supabase
```

## Запуск

Пока код приложения не создан. Этот раздел появится вместе с `web/`.

## Переменные окружения

Секреты не хранятся в репозитории. Шаблон переменных — в `.env.example`. Реальные значения хранятся в `web/.env.local` (он в `.gitignore`).
