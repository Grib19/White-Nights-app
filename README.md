# White Nights

Социальная сеть с сайтом (компьютер и телефон), приложением для Android и приложением для Windows.

## Планируемый стек

| Часть | Технология | Назначение |
|---|---|---|
| Бэкенд | Supabase | Авторизация, база данных Postgres, хранение файлов, обновления в реальном времени |
| Сайт | Next.js (React) | Один код для компьютеров и телефонов |
| Android | Capacitor | Оболочка над сайтом для установки на Android |
| Windows | Tauri или Electron | Оболочка над сайтом для установки на Windows |
| Хостинг сайта | Vercel | Автоматическая публикация при обновлении `main` |

Стек предварительный и уточняется после обсуждения идеи.

## Структура

```
docs/             описание идеи, функций, решений
web/              сайт (Next.js), общий для всех платформ
mobile-android/   сборка Android через Capacitor
desktop-windows/  сборка Windows через Tauri или Electron
supabase/         миграции базы данных и настройки Supabase
```

## Запуск

Пока код приложения не создан. Этот раздел появится вместе с `web/`.

## Переменные окружения

Секреты не хранятся в репозитории. Шаблон переменных — в `.env.example`. Реальные значения хранятся в `.env.local` (он в `.gitignore`).
