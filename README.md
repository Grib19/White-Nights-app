# White Nights

Социальная сеть студенческого отряда проводников «Белые Ночи» (СОП): сайт для компьютера и телефона, приложения для Android и Windows — в планах.

## Что уже работает

- Вход по почте и паролю; после регистрации аккаунт подтверждает комсостав.
- Роли: Кандидат, Боец, Мастер, Комиссар, Командир; комсостав — Мастер, Комиссар и Командир.
- Профили: публичные данные для всех, закрытые (паспорт, ИНН, СНИЛС и другие) — только себе и комсоставу.
- Участники: список и карточка участника.
- Информация: документы отряда — тексты и PDF.
- Музыка: плеер песен отряда; загружает и удаляет песни комсостав.
- Лента: «Важное» и «Посты», фото и файлы до 20 МБ, опросы, реакции, комментарии, подгрузка старых постов.
- Чаты: общий, комсостава, групповые и «Избранное»; ответы, закрепление, пересылка, выделение, медиа-вкладки, поиск, упоминания, админы групп, расшифровка голосовых.
- Звонки: аудио, видео и демонстрация экрана, до 10 участников.
- Задачи: список, доска в стиле Trello, календарь, подпункты, подтверждение выполнения, напоминания, история.
- Холст и видеокружки в чате.
- Push-уведомления и напоминания о задачах по расписанию.

## Стек

| Часть | Технология | Назначение |
|---|---|---|
| API | Cloudflare Workers (TypeScript) | серверная логика и проверка прав, бесплатно до 100 000 запросов в день |
| База | Cloudflare D1 (SQLite) | пользователи, посты, задачи, доски и остальное, до 5 ГБ |
| Файлы | Workers KV | фото до 5 МБ, вложения и аудио до 20 МБ |
| Реальное время | Ably | сообщения чатов и сигнализация звонков |
| Звонки | WebRTC и Cloudflare Calls TURN | до 10 участников |
| Расшифровка | Cloudflare Workers AI (Whisper) | текст голосовых и видеокружков |
| Push | Web Push (VAPID) | уведомления при закрытом сайте |
| Сайт | React 18 и Vite 5 | один код для компьютера и телефона |
| Android и Windows | Capacitor и Tauri | пока не начаты |

## Структура

```
docs/             описание идеи и решений
web/              сайт (React и Vite)
api/              сервер Cloudflare Workers и миграции D1
api/migrations/   миграции базы, применяются по порядку
tools/            служебные скрипты (загрузка песен)
mobile-android/   заготовка для Android
desktop-windows/  заготовка для Windows
```

## Запуск

### Сервер

```
cd api
npm install
npx wrangler d1 migrations apply white-nights-db --local
npx wrangler dev
```

Локальные секреты кладутся в `api/.dev.vars`, на сервере — через `npx wrangler secret put <имя>`.

### Сайт

```
cd web
npm install
npm run dev
npm run build
```

Адрес API задаётся в `web/.env.local`: `VITE_API_URL=http://127.0.0.1:8787` для локального сервера или адрес развёрнутого.

## Секреты

| Секрет | Зачем |
|---|---|
| `ABLY_API_KEY` | чаты и сигнализация звонков |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | push-уведомления (`npx web-push generate-vapid-keys`) |
| `TURN_KEY_ID`, `TURN_KEY_API_TOKEN` | TURN для звонков в мобильных сетях |

Секреты не хранятся в репозитории. Шаблон переменных сайта — `.env.example`.

## Развёртывание

```
cd api
npx wrangler d1 migrations apply white-nights-db --remote
npx wrangler deploy
```

```
cd web
npm run build
```

Готовые файлы из `web/dist` подходят для Cloudflare Pages. Сайт на Pages пока не опубликован.
