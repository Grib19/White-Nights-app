# web

Сайт White Nights: React, TypeScript, Vite. Подходит и для компьютеров, и для телефонов.

## Запуск

```
cd web
npm install
npm run dev
```

Переменные Supabase задаются в `web/.env.local` (шаблон — `.env.example` в корне проекта, с префиксом `VITE_`).

Статус: основа создана, сборка на компьютере пока не проверена.
